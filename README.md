# CustomProfiles (Sync Server)

The sync server is provided as a single `.mjs` file.

## Running the Server

1. Install a recent version of Node.js.
2. Download or clone the project files.
3. Open a terminal in the folder containing the `.mjs` file.
4. Start the server:

```bash
node server.mjs
```

If your file has a different name, replace `server.mjs` with the correct filename.

## Notes

- The sync server is completely optional and is only required if you want profile data to be synchronized between devices.
- Any configuration options can be found directly inside the server file.
- If something explodes, catches fire, or summons a demon, check the terminal output first.
